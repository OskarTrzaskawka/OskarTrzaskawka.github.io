# Security Policy

Persona Folio is a static site with no backend, but if you find a security issue
(for example XSS through persona data, or a dependency vulnerability), please
**do not open a public issue**.

Report it privately via
[GitHub Security Advisories](https://github.com/OskarTrzaskawka/persona-folio/security/advisories/new)
or contact the maintainer on the [Discord support server](https://discord.com/invite/U5fzuzbgkF).

You will get a reply within a few days. Thank you for helping keep the project safe.
